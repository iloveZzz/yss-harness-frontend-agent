# 产品设计影响与原型

UI 影响与产品设计影响分别判定。主流程、导航、权限体验、异常/恢复、状态流转或 API 反推才触发页面流、状态矩阵和原型校准；纯文案、token、间距或无行为的孤立视觉修复不自动触发完整产品设计。

命中产品设计影响时由 `yss-prototype-stage` 统一生成离线 HTML，视觉规范为根 `DESIGN.md`；真实生产组件在实现阶段核验。正式 UI 切片在 ready-for-agent 前需要有效前端实现计划，实现后留截图/视觉、状态、交互、console warning 和真实命令退出码证据。

原型用于验证产品设计，不替代生产实现、OpenAPI 或 Slice 合同。生产还原需同一页面、视口与交互状态的可定位基线及允许差异，不能仅凭截图或 type-check 宣布还原通过。

本仓只承担前端交付；另一端角色仅提供只读输入评审，不获得另一端代码写范围。本端完成不代表跨端业务验收，统一管理方核验整体证据。 参见 [[Spec基线]]、[[Fresh验证与独立审查]]。
